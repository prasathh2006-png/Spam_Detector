#Spam Email Detector

Spam email classifier using Naive Bayes with 98.56% accuracy on 5,572 SMS messages | Python, Scikit-learn, NLP
## Overview
Machine Learning project to classify SMS messages as Spam or Ham using Natural Language Processing techniques. Built as part of Amazon ML Summer School 2026 application.

## Dataset
- **Source:** UCI ML Repository - SMS Spam Collection
- **Size:** 5,572 messages
- **Classes:** Spam, Ham

## Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-learn
- **Algorithm:** Multinomial Naive Bayes
- **Vectorization:** CountVectorizer

## Results
- **Accuracy:** 98.56%
- **Key Learning:** Understood end-to-end ML workflow, text preprocessing, and NLP fundamentals

## How to Run
1. Open `Spam_Detector.ipynb` in Google Colab
2. Run all cells sequentially
3. Output shows 98.56% accuracy
